### 📜 서비스 내용

이번 프로젝트는 급증하는 헬스트랜드에 맞춘 헬스장 전용 웹 서비스입니다사용자가 쉽고 편리하게 이용할 수 있도록 실시간 레슨 예약, 홈 트레이닝 영상제공, 운동기록 관리 기록, 이용자들의 소통의장을 제공하여 더 나은 사용자 경험을 제공합니다.

# 개발 내용

## 📝 게시판 기능

- 오운완 : 서로의 운동 기록들을 공유하는 공간
- 홈트레이닝 : 다양한 홈 트레이닝 영상을 제공
- 그룹 : 운동 그룹을 생성하여 서로의 운동 공유 및 그룹챌린지 참여기능
- 공지사항: 헬스장 공지사항 제공 기능

🔍 기능 설명

- 게시판 CRUD 구현
- 댓글,좋아요,저장 기능 추가

## 📝 이용권 및 쿠폰

- 구매 : 헬스장 이용권 및 PT이용권 구매
- 쿠폰 : 이용권 할인기능
- 양도: 회원 간의 이용권 양도기능

🔍 기능 설명

- 이용권 및 쿠폰 CRUD 구현
- 결제 시스템 연동(TOSS API 사용)

## 📝 출석 및 현재 이용객 수 제공

- 헬스장 이용객 수 제공으로 쾌적한 환경 제공

🔍 기능 설명

- 출석 체크 기능 구현(1일 1회 횟수 제한)
- 출석 기록 조회

## 📝 챌린지 기능

- 다양한 챌린지 참여

🔍 기능 설명

- 챌린지 CRUD 기능 구현
- 챌린지 참여율 계산 로직 구현

## 📝 레슨 기능

- 트레이너별 레슨 일정 관리
- 회원의 PT레슨 예약 및 조회 기능

🔍 기능 설명

- 레슨 CRUD 기능 구현
- 레슨 신청 , 예약 , 취소 기능 구현
- 레슨 시작 1시간전 예약 마감, 예약한 회원의 이용권 횟수 1회 차감

## 📝 채팅기능

- 트레이너와 회원 간의 실시간 채팅 기능
- 그룹원들과 그룹채팅 기능

🔍 기능 설명

- 실시간 채팅 기능 구현(WebSocket-Stomp 사용)
- 알람기능 구현 → 채팅방에 접속되어있는 유저는 알람기능에서 잠시 제외
